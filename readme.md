# 我是谁？
我目前任职于腾讯金融科技（FiT）条线，担任产品经理，隶属于智能应用团队，主要负责腾讯自选股 App 中 AI 应用及 Agent 能力的设计与落地。在此之前，我曾就职于光大证券和华泰期货，参与证券与期货类应用的产品迭代与优化工作。

# 为什么写产品手册？

2022 年年末，我当时在一家小公司已经工作 2 年了，随后离职来到了光大证券。初到“大厂”，我发现能力远未达标，于是我在每天工作之余都在学习产品经理相关的知识。

随后我在想，为什么不写出来呢？我当时曾听说过某个学习方法（费曼学习法），将知识用自己的语言表述出来，效果会比死记硬背更好。这就是我开始写这本手册的原因。

当然除了和产品经理相关的部分，我还记录了一些书单、随想和很早之前做过的作品集等等，这些内容都在手册中，你可以随意浏览。不过部分和 AI 相关的内容可能是 2 年前的产物，你可以忽略我当初对它们的看法，毕竟现在 AI 发展的太快了。

在此之前，我将这些知识部署在购买的域名上，但懒得维护，索性放在 Github 上开源。如你所见，你可以在此开启新手产品从零开始学习的过程。

# 产品知识  /docs/Product
## /fundamentals

- /career

定义产品经理的角色边界、核心素质与职业发展路径。深入探讨“产品思维”这一核心认知，以及如何辨别真伪需求。

- /design

涵盖从宏观（战略与价值）到微观（功能实现）的全链路设计。包含 Scrum敏捷开发流程、进度管理，以及竞品分析和行业分析等系统化方法论。

## /general-skills

- /what-is

解析驱动产品成功的核心商业概念与经济学原理。理解增长与可持续发展背后的底层逻辑（如飞轮效应、网络效应、单位经济模型）。

- /workplace-skills

职场生存与进阶实战指南。涵盖面试策略、OKR目标管理、个人效率提升，以及周报撰写的意义等实用技能。

## /operations
- /career

探讨数据分析体系、增长策略以及运营与产品的协同。包含运营职业路径规划以及如何成功转岗产品经理的实战建议。

- /practice

产品经理技能的真实应用。包含深度竞品调研、复杂项目拆解方法论，以及针对搜索系统等特定功能的深度设计分析。

- /reading

精选企业史、产品理论相关的书单推荐，以及产品作品集分享。
